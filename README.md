# **Desenvolvendo Funções**
### **O que foi feito**
Nesta branch, reorganizei o código utilizando funções e adicionando algumas funcionalidades que achei interessante adicionar ao jogo.

---

### **Funcionalidades adicionadas**
- Criação de uma função para normalizar acentos, permitindo comparar letras acentuadas e não acentuadas.
- Criação de uma função para exibir as regras do jogo.
- Criação de uma função para ler e validar a letra digitada pelo jogador.
- Validação para aceitar apenas uma letra por tentativa.
- Validação para impedir a entrada de caracteres que não sejam letras.
- Criação de uma função para verificar letras repetidas.
- Armazenamento das letras já tentadas pelo jogador.
- Criação de uma função para montar e exibir a palavra parcialmente revelada.
- Contagem do número total de tentativas.
- Contagem das tentativas erradas.
- Criação de uma função para mostrar as partes do corpo adicionadas à forca.
- Criação de uma função para verificar se o jogador perdeu a partida.
- Criação de uma função para verificar se o jogador venceu a partida.
- Criação de uma função para permitir que o jogador continue ou encerre o jogo.
- Organização do fluxo principal do jogo por meio das funções Jogar() e main().

---

### **Objetivo da atualização**
O objetivo desta versão é aplicar os conceitos de **funções**, modularização, validação de dados, estruturas de repetição e **organização de código**, facilitando futuras melhorias e a manutenção do projeto.
